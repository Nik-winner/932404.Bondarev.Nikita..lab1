## Реализованный структура
В проекте строго соблюдены все требования технического задания:

- **Семантическая разметка HTML5:** Использованы теги `<header>`, `<main>`, `<section>`, `<aside>`, `<footer>`.
- **Основной контент (`<main>`):**
  - **Секция «Навыки»:** Маркированный список (`<ul>`) с социальными и организационными компетенциями (фандрайзинг, координация, работа с НКО).
  - **Секция «Проекты»:** Нумерованный список (`<ol>`) из 4 волонтёрских инициатив.
  - **Изображение:** Аватар с обязательными атрибутами `src`, `alt`, `width`, `height`.
  - **Форма обратной связи:** Поля «Имя» (`type="text"`), «Email» (`type="email"`), «Сообщение» (`<textarea>`), кнопка отправки. Все поля имеют атрибуты `name` и `placeholder`.
- **Боковая панель (`<aside>`):** Блок с описанием социальной проблемы, которая волнует автора (одиночество пожилых людей).
- **Шапка (`<header>`) и Подвал (`<footer>`):** Содержат имя студента, заголовок страницы и информацию об авторском праве с указанием года.
- **Дизайн:** Красно-белая цветовая схема, адаптивная Flexbox-верстка для удобного отображения на разных экранах.
